# Food Corner — Restaurant Website

A responsive restaurant landing page built with HTML, CSS, and JavaScript, based on the supplied demo video.

## Features
- Sticky burgundy header and in-page navigation
- Hero section with food photography
- About Us section
- Popular dishes with descriptions and prices
- Why Choose Us cards
- Contact/location section and footer
- Responsive layout for mobile and desktop

## Run in VS Code
1. Extract this project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension.
4. Internet access is needed for the remote food photos and Google Fonts.

## Customize
Update the restaurant address, phone number, email, dish descriptions, prices, and photos in `index.html`.
